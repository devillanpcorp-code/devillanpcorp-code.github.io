DocMuDc

Comic → Shorts pipeline

DocMuDc is a personal, locally-run application that turns comic book pages into short-form video scripts and assembled videos. It runs entirely on the owner's own machine and is not a public service, SaaS product, or hosted app — this page exists solely to satisfy Google's OAuth application requirements for the app's own YouTube Analytics integration.

DocMuDc's YouTube Analytics integration reads retention and click-through data for videos on the owner's own YouTube channel, using a read-only scope (yt-analytics.readonly), so the pipeline can show real performance numbers on its own dashboard and suggest style improvements based on that data.

See the Privacy Policy for details on how this data is used and stored.
